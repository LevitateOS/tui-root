      Rec Tooling          ▸       What is LevitateOS and why does it exist?
                                 A
                                   LevitateOS is a daily driver Linux distribution
                                   competing directly with Arch Linux. It borrows Arch's
                                   philosophy (you maintain your own packages on a
                                   minimal base) but takes its core system (glibc,
                                   systemd, coreutils, OpenSSH and the rest of a minimal
                                   base) pre-built from Fedora instead of compiling it,
                                   and it updates atomically: A/B slots by default, with
                                   a trial boot before each update is kept.
                                   Dimension   Arch Linux          LevitateOS
                                   Target      Power users         Same
                                   User        seeking control
                                   Philosophy  Minimal base, user  Same
