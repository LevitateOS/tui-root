│    How We Compare            ││   LevitateOS is a daily driver Linux distribution competing directly with Arch       │
│    Atomic Updates (A/B)      ││   Linux. It borrows Arch's philosophy (you maintain your own packages on a minimal   │
│    Variants                  ││   base) but takes its core system (glibc, systemd, coreutils, OpenSSH and the rest   │
│                              ││   of a minimal base) pre-built from Fedora instead of compiling it, and it updates   │
│ ▸ Rec Tooling                ││   atomically: A/B slots by default, with a trial boot before each update is kept.    │
│                              ││   Dimension       │ Arch Linux                  │ LevitateOS                         │
│                              ││   ────────────────┼─────────────────────────────┼─────────────────────────────────   │

│                              ││   Philosophy      │ Minimal base, user builds   │ Same                               │
│                              ││   Package Manager │ pacman + AUR                │ recipe (Rhai scripts)              │

│                              ││   Updates         │ In place                    │ A/B slots, trial boot, rollback    │
